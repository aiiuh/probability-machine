## Coverage and excluded identities

The public Probability Machine baseline was pinned at commit `1185305da225357be10d7f6286951a4d138b633e` before edits. Existing local source came from its earlier attached package; a live repository read confirmed the baseline contents/tree. The original 64 tests were rerun before extension.

Public GitHub search found multiple unrelated projects called Weft. `temo-pacheco/weft` and `alexisreal/weft` are literate-programming tools and were explicitly excluded as evidence about the existing Machine runtime. Exact runtime identity and deployed guarantees remain to be inspected through the authorized bridge.

Live X bookmarks were not available. A saved social screenshot supplied leads only. “Executor” was not uniquely resolved; no guessed project was installed. The absence of a live source is a missing-coverage entry, not an empty bookmark collection.

## Executed evidence

The reference core, existing decision code, synthetic data transformations, local temporary-file write/read-back, failure tests and candidate selection were actually executed. Results are reproducible using the commands in `CORE_HANDOFF.md`. Generated fixture agreement is not a human study, learned-model benchmark, security audit or proof of broad agent reliability.
